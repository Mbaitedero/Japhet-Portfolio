# Japhet Portfolio

Portfolio personnel présentant mon parcours, mes projets et mes compétences en Data Science / Intelligence Artificielle, avec téléchargement direct de mon CV.

## 🛠️ Stack technique

React · TypeScript · Vite · Tailwind CSS

## ✨ Contenu

- Présentation et parcours
- Mise en avant des projets clés (dont [Fraude-Detection-MLOPS](https://github.com/Mbaitedero/Fraude-Detection-MLOPS))
- Compétences techniques
- CV téléchargeable
- Formulaire de contact

## 🚀 Lancer le projet en local

```bash
npm install
npm run dev
```
